# 🛒 Pickaboo E-Commerce Testing Project

## 📌 Project Overview
This project demonstrates end-to-end manual and API testing of an e-commerce platform (Pickaboo simulation).

## 🎯 Objective
To validate core functionalities including login, product search, cart management, and checkout process.

---

## 🧪 Testing Scope
- Login & Registration
- Product Search & Filtering
- Product Details Page
- Add to Cart / Remove from Cart
- Checkout Process

---

## 🛠 Tools & Technologies
- Manual Testing
- Postman (API Testing)
- Excel (Test Cases & Bug Reports)
- GitHub (Version Control)
